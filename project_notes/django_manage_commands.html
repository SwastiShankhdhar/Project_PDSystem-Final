python manage.py commands

Django + PostgreSQL + DRF + ML — full reference

Database

python manage.py makemigrations

Detects changes in your models and generates migration files. Run after every model change.

database

python manage.py migrate

Applies pending migrations to PostgreSQL — actually creates/alters tables on the DB.

database

python manage.py showmigrations

Lists all migrations and whether they have been applied [X] or not [ ].

database

python manage.py sqlmigrate <app> <migration>

Prints the raw SQL that a migration will execute — great for checking before applying.

database

python manage.py dbshell

Opens a live psql terminal connected to your PostgreSQL database.

database

python manage.py inspectdb

Reverse-engineers your existing DB tables into Django model code.

database

python manage.py flush

Wipes all data from the DB tables but keeps the table structure intact.

database

Testing

python manage.py test

Runs the full test suite — creates a temporary test DB, runs all tests, destroys it.

test

python manage.py test <app>

Runs tests only for a specific app — e.g. test detection for your ML app.

test

python manage.py test <app>.tests.<Class>.<method>

Pinpoints a single test method — useful for debugging one failing case.

test

python manage.py test --verbosity 2

Shows each test name as it runs instead of just dots — much easier to debug.

test

python manage.py test --keepdb

Reuses the test DB between runs — faster, especially with PostgreSQL migrations.

test

DRF & API

python manage.py generateschema

Generates an OpenAPI schema file for your DRF API endpoints.

DRF

python manage.py shell

Interactive Python shell with all your Django models, serializers, and settings pre-loaded.

DRF

Development

python manage.py runserver

Starts the dev server at localhost:8000. Add 0.0.0.0:8000 to expose on network.

dev

python manage.py startapp <name>

Creates a new app folder with models, views, tests, etc. pre-scaffolded.

dev

python manage.py check

Validates your entire project for config errors, missing migrations, model issues — without running the server.

dev

python manage.py check --deploy

Runs extra security checks for production readiness — DEBUG off, secret keys, HTTPS, etc.

dev

python manage.py collectstatic

Gathers all static files into STATIC_ROOT for serving in production.

dev

Admin & data

python manage.py createsuperuser

Creates an admin user to log into the Django admin panel at /admin.

admin

python manage.py changepassword <username>

Resets a user's password directly from the terminal.

admin

python manage.py dumpdata > backup.json

Exports all DB data to JSON. Use loaddata backup.json to import it back.

admin

python manage.py help

Prints every available command including any custom ones you've written.

admin
